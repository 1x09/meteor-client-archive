Meteor Client Archive

Source snapshots of every tagged version of Meteor Client, plus the full git history. Unofficial mirror, not affiliated with the Meteor Development team. Meteor Client is GPL-3.0 licensed.

Full history (all branches and tags, 48 MB): meteor-client-full-history.bundle 
git clone meteor-client-full-history.bundle meteor-client
Building a version: extract a zip, then run ./gradlew build. The jar is created in build/libs/. Older versions need older JDKs and target older Minecraft versions, so check each one's README.
Prebuilt jars are not on GitHub releases; get them from the official site, meteorclient.com.
